# Claim-Level Citation & Provenance Rules

## Non-Negotiable Citation Principles (spec §34-37)

1. **Deterministic URLs**: URLs used in citations come **ONLY** from stored database metadata. The LLM is never permitted to invent URLs.
2. **Claim-Level Mapping**: Generated answers return structured claims where every material assertion points to specific evidence IDs (e.g. `[E001]`).
3. **Evidence Support Verification**: Post-generation validator verifies that cited evidence exists and contains relevant textual support.
4. **Invented Citations Rejected**: Any citation ID generated by the model that does not map to a retrieved evidence item is stripped and flagged as an uncertainty.
